## 10. What a future AI agent must NOT break (invariants) + safe extension points

### Do-not-change (without explicit user approval + migration + test)
1. **DB schema & RPC contracts:** the 29 RPC names/signatures above (esp. `create_faculty_course(p_payload)`, `get_student_course_plan`, `get_student_lesson_access`, `submit_quiz_attempt`, `complete_lesson`, `join_live_session`, `delete_course_with_content`, `clone_course*`); table names in §4; `profiles.role` enum `student|faculty|super_admin`; `course_faculty` as the join that makes a course visible to faculty (#43 is the proof).

5. **Grading integrity:** scores computed **only** from actual stdout in `secure-grade`; never trust client-submitted scores; the `api/execute.py` / go-judge token must never leak into executed student code (sanitized env, `-I` isolated mode). `secure_grading_runs` FK cascades matter (`20260912130000_*`).
6. **Lesson release gating:** lessons unlock only on real joins / explicit release (`release_lesson_*`, `lesson_releases`); the "release only on join" rule (PR #38, `20261008120000_release_only_on_join.sql`) is a deliberate product decision, not a bug.
7. **Notifications outbox:** `notifications` outbox + pg_cron driver; mailer is fail-closed (`MAILER_PROVIDER` unset → log, don't send); `NOTIFICATION_*_TOKEN` service-to-service auth on `notification-mailer`/`notification-push`.
8. **Migrations:** append-only, `YYYYMMDDHHMMSS_name.sql` order; never edit an applied migration; never squash without a prod backup + `repair_baseline` plan (drift already happened twice).
9. **External contracts:** Canva short-link resolution must stay server-side (`resolve-canva-link` — client-side fabrication was a real bug, #19); the `#auth_handoff` refresh-token fragment to the coding dashboard (`src/lib/externalLinks.ts`) — do not "fix" by moving the token to a query param or localStorage share; workshop/lead ingest secrets (`KAVERI_WORKSHOP_INTEGRATION_SECRET`, `KAVERI_LEAD_API_SECRET`).
